# 项目结构与重要文件概览

下方 ASCII 结构树和说明帮助快速定位核心组件及其作用，并标注关键文件/目录。

```
wifi-densepose/
├─ rust-port/
│  └─ wifi-densepose-rs/
│     ├─ Cargo.toml            (Rust 工作区入口，聚合各 crate)
│     └─ crates/
│        ├─ wifi-densepose-signal/    (CSI 信号处理与频域/相位清洗)
│        ├─ wifi-densepose-train/     (训练与数据流水线)
│        ├─ wifi-densepose-nn/        (推理与 DensePose 头)
│        ├─ wifi-densepose-hardware/  (硬件/ESP32 接口与聚合)
│        └─ ...                       (其他支持 crate：配置、API、WASM 等)
├─ v1/                         (Python 参考实现与测试套件)
│  ├─ src/                     (Python 代码)
│  └─ data/proof/verify.py     (确定性 CSI 流水线验证脚本)
├─ firmware/
│  └─ esp32-csi-node/          (ESP32-S3 CSI 采集与 UDP 推流固件)
├─ docs/                       (用户指南、构建文档、ADR 架构决策)
├─ docker/                     (Docker/Compose 部署配置)
├─ ui/                         (Web UI 控制与可视化)
├─ scripts/                    (自动化与运维脚本)
├─ logging/ & monitoring/      (Fluentd/Prometheus/Grafana 可观测性)
├─ README.md / CHANGELOG.md    (项目总览与变更记录)
└─ example.env / configs       (环境变量与样例配置)
```

## 重要文件/目录速览
- **rust-port/wifi-densepose-rs/Cargo.toml**：Rust 工作区入口，定义各 crate。
- **rust-port/wifi-densepose-rs/crates/wifi-densepose-signal/**：CSI 信号清洗、滤波、特征提取核心逻辑。
- **rust-port/wifi-densepose-rs/crates/wifi-densepose-train/**：训练/数据加载与 ruvector 集成。
- **v1/data/proof/verify.py**：使用参考 CSI 证明包验证完整信号处理链路。
- **firmware/esp32-csi-node/**：ESP32-S3 固件源码，负责现场采集 CSI 并推流。
- **docs/adr/**：架构决策记录（ADR-001~），了解设计取舍。
- **docs/user-guide.md & docs/build-guide.md**：用户入门、硬件/软件安装与构建指南。
