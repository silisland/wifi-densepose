# 硬件资源与能力分析

## 可用设备举例
- **ESP32-S3 Mesh（推荐）**：3~6 个节点 + 普通路由器；全 CSI，支持姿态/呼吸/心率/穿墙感知。
- **研究级网卡**：Intel 5300、Atheros AR9580 等；全 CSI，3x3 MIMO，可做精细建模与多 AP 实验。
- **通用 WiFi 设备（笔记本/路由器）**：仅 RSSI，适合粗粒度在场/移动检测，无法做精细姿态。

## 能力与用途
- **人体姿态与关键点**：基于 DensePose/关键点回归，提供 17 关节或 UV 映射。
- **生命体征**：呼吸（6-30 BPM）、心率（40-120 BPM）远距离无接触测量。
- **穿墙/遮挡感知**：利用 Fresnel 区与多径建模，可穿透墙体/家具/烟雾。
- **存在/占用检测**：低延迟 (<1s) 触发，可用于安防、能耗优化、场地管理。

## 交互与集成方式
- **数据输入**：设备通过 UDP/串口将 CSI 推送到聚合器（`wifi-densepose-hardware` + `esp32-csi-node`）。
- **服务接口**：REST/CLI/UI 暴露实时姿态、生命体征与事件；可接入 Prometheus/Grafana。
- **部署形态**：Docker/Compose 一键启动；也可在本地 Rust 可执行或浏览器 WASM 运行。
- **上层联动**：可与 HVAC/安防/机器人等系统通过 API 或消息总线集成，实现自动化控制与联动。
